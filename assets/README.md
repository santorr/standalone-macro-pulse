# MacroPulse identity

- `macropulse.png`: original RGBA image generated with the integrated ImageGen tool, 1,254 × 1,254.
- `macropulse.ico`: Windows icon derived from that image, with 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel sizes and preserved transparency. Embedded in the executable, title bar and navigation.

The interface uses a dark purple gaming-inspired palette. The MacroPulse symbol is an original design. Small control icons are drawn in code so they stay sharp at different DPI scales.

## Original generation prompt

> Use case: logo-brand. Create a production Windows desktop application icon for MacroPulse, a fast mouse and keyboard macro tool. Single centered bold geometric monogram merging an M, a cursor arrow, and a pulse/bolt motif. Modern premium gaming-software aesthetic: luminous lavender and electric violet with a small icy cyan highlight, on a very dark indigo rounded-square tile. Subtle polished dimensional bevel, restrained soft glow, crisp thick edges and simple silhouette legible at 24x24 pixels. Icon fills 85% of square with balanced padding. Genuine transparent background outside the rounded tile. No text, no words, no additional letters, no tiny details, no device mockup, no surrounding scene. Square 1024x1024. Original brand identity, do not reproduce any existing brand logo.
