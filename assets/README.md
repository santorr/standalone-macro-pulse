# Identité MacroPulse

- `macropulse.png` : original RGBA généré avec l'outil **ImageGen intégré**, 1 254 × 1 254.
- `macropulse.ico` : conteneur Windows issu de cette image, tailles 16, 20, 24, 32, 40, 48, 64, 128 et 256 pixels, transparence conservée. Intégré aux ressources de l'exécutable, à la barre de titre et à la navigation.

L'interface s'inspire des palettes sombres et violettes des applications gaming telles que [Mobalytics](https://mobalytics.gg/blog/lol-how-to-use-mobalytics-overlay-live-companion/). Le symbole MacroPulse est une création originale. Les petites icônes de contrôle sont dessinées en code pour rester nettes à toutes les échelles.
