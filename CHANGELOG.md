# Historique des versions

## 1.4.0

- Bibliothèque intégrée de macros, édition, duplication et sauvegarde automatique.
- Restauration de la session et migration des anciens fichiers `.mpulse`.
- Préférences, raccourcis configurables et interface Windows en français.
- Distribution portable Windows 10/11 x64, runtime MSVC statique.
- Publication GitHub : tests Debug/Release, packages versionnés et empreintes SHA-256.

Les versions futures suivent `MAJEUR.MINEUR.CORRECTIF` ; voir le processus de release dans le README.
